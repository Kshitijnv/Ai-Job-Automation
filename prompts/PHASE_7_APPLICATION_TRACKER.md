Track application history locally.

Create:

`data/applications.json`

```json
{

    "company":"FIS",
    "status":"Applied",
    "portal":"Workday",
    "resume":"FIS_Resume.pdf",
    "appliedOn":"2026-09-29"
  }
}
```
